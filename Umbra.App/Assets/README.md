# Media assets

- `Ambient/Images` contains the thumbnails for the bundled ambient catalogue.
- `Ambient/Sounds` contains the CC0 recordings listed in the repository's
  `THIRD_PARTY_NOTICES.md`.
- `Backgrounds` and the PNG files in `FloatingBackgrounds` are the static
  appearance presets shipped with Umbra.

Animated third-party MP4 wallpapers are intentionally ignored and are not part
of public builds. Users can choose their own PNG, JPG, or MP4 background from
Settings.
